# DRAW DESK · 그림 공방

독립 정적 Pages 그림 도구. 화면 크기에 종속되지 않는 부동소수점 스트로크·도형·글자 문서, 레이어 합성과 고해상도 렌더링을 제공합니다. 처음 열리는 해안선 그림은 직접 편집할 수 있는 샘플입니다. `새 문서`로 빈 캔버스를 만들 수 있습니다.

## 기능

- 브러시/연필/마커, 펜압 굵기, 흔들림 보정, 레이어에만 적용하는 지우개, 직선/사각형/타원/글자.
- 선택·이동·모서리 크기 조절, 중심 X/Y·너비/높이·회전 숫자 편집, 방향키 0.1px 또는 Shift 10px 이동, 복제/삭제.
- 최대 16레이어, 표시·잠금·이름·순서·0.01 단위 불투명도와 보통/곱하기/스크린/오버레이 합성.
- 확대/이동/맞춤, Space+드래그, Ctrl/Cmd+휠, 터치 두 손가락 확대. 자동 맞춤 상태에서는 창 크기 변경에 따라 맞춤을 갱신합니다.
- SENSE LAB에서 옮긴 패턴 창작: 끌어당김/밀어냄/나선 궤적, 12–160 입자, 궤적 길이, 0.001 단위 힘, 팔레트와 시드. 정지된 편집 가능 벡터 레이어를 만들며 다른 그림과 합치고 실행 취소할 수 있습니다.
- 편집 JSON 저장/불러오기, 원본 모델을 다시 그리는 PNG와 XML 이스케이프된 벡터 SVG. PNG는 캡처 화면을 확대하는 방식이 아닙니다. SVG 글자는 열람 기기의 해당 기본 글꼴이 필요합니다.

## 크기와 저장

문서 가장자리 256–8192px, 최대 32메가픽셀. PNG의 긴 변도 최대 8192px이며 면적 한도를 초과하면 거절합니다(예: 기본 3:2 문서의 8192 긴 변은 32MP 초과). 기본 4096 긴 변은 4096×2731로 출력합니다. 미리보기는 현재 화면의 픽셀 밀도에 맞추며 원본 좌표는 유지합니다. 출력 버퍼 예상 메모리를 표시하고 실패 시 작업을 보존합니다.

최대 5000개체, 300000점, 스트로크당 50000점, 레이어당 64지우개, JSON 40MB. 실행 취소는 최대 60상태/48MB이며 오래된 상태부터 줄어듭니다. 무제한 문서·전문 색상 관리/CMYK/PSD/모든 펜 기기의 호환성을 보장하지 않습니다.

독립 `draw-desk-project-v1` 키에 최대 4MB를 자동 저장합니다. 손상된 기존 문서는 덮어쓰지 않으며 명시적인 새 문서/불러오기로 교체할 때만 복구합니다. 용량·저장 오류는 표시합니다. 더 큰 문서는 직접 작업 파일을 내려받아 보관하세요. 다운로드 요청이 곧 파일 저장 완료라는 가정을 하지 않으므로 확인되지 않은 변경에는 페이지 이탈 경고가 남을 수 있습니다. 다른 탭의 업데이트는 안내만 하고 현재 작업을 자동으로 교체하지 않습니다.

서버·계정·광고·마이크·분석·업로드·외부 런타임 요청·공개 점수는 없습니다. 기존 앱의 공유 완료 키를 읽거나 쓰지 않습니다. 같은 Pages 출처의 저장소는 경로별 접근 격리가 아니므로 민감한 개인정보를 담지 마세요.

## 실행 / 검증

Node 22 이상. 패키지 설치 없이 `npm run dev`, `npm test`, `npm run check`. `architecture.md`와 `requirements.md`, `docs/decisions.md`, `docs/verification.md`에서 설계·정책·검증 상태를 확인합니다. Actions는 테스트/자산 검사를 통과한 dist만 배포합니다.

UI 글꼴은 [Pretendard Variable v1.3.9](https://github.com/orioncactus/pretendard/tree/v1.3.9) 원본이며 SIL OFL 1.1 저작권/라이선스를 `dist/assets/fonts/OFL.txt`에 그대로 포함합니다. 글꼴 파일은 수정하지 않았고 같은 출처에서만 읽습니다. 사이트 코드에 별도의 라이선스는 부여하지 않았습니다.
